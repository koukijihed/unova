# UNOVA

Plateforme numérique de l'ESSECT à Tunis.

> Votre université, un seul espace numérique.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans le navigateur.

## Scripts

- `npm run dev` : serveur de développement.
- `npm run lint` : vérification ESLint.
- `npm run build` : build de production.
- `npm run start` : serveur de production.

## Structure

- `src/app` : routes et layouts de l'App Router.
- `src/components` : composants d'interface.
- `src/lib` : utilitaires et accès aux données.
- `src/content/fr.ts` : chaînes de l'interface en français.
- `docs/STATUS.md` : état du projet (Implémenté / Prévu).
